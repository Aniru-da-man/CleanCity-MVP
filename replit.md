## Architecture decisions

- All API data is mock data served from Express routes Ã¢â‚¬â€ no database required for the first version. DB integration can be added later by replacing mock data with Drizzle queries.
- OpenAPI-first contract: all hooks are generated by Orval from `lib/api-spec/openapi.yaml`.
- Frontend uses hardcoded fallback mock data when the API returns errors, ensuring the UI always looks data-rich.
- Dark mode is the default theme (deep navy + cyan/emerald palette). Light mode is also supported via next-themes.
- Map page uses react-leaflet with OpenStreetMap tiles (no API key required).

## Gotchas

- After any change to `lib/api-spec/openapi.yaml`, run `pnpm --filter @workspace/api-spec run codegen` before touching frontend code.
- The `notifications/read-all` route must come before `notifications/:id/read` in Express to avoid route conflicts.
- Leaflet requires `import 'leaflet/dist/leaflet.css'` and a manual fix for default marker icons.
